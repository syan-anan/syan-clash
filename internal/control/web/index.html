每个节点依次探测真接口：ChatGPT 走 chatgpt.com 首页与 /api/auth/session（站点能从该出口打开就算可用——Cloudflare 的托管挑战交给浏览器自证，内置登录窗口就是浏览器）； Gemini 走 aistudio.google.com/prompts/new_chat（跳转到 docs/available-regions 就是地区不可用）、 gemini.google.com/app 与 generativelanguage.googleapis.com。 可用=服务从该出口可达、地区受支持，不需要登录；需过验证=被硬封禁或限流； 地区不支持=服务明确拒绝该地区。每格的悬停提示里有状态码、命中关键字、最终地址、出口 IP 与检测时间，可以复核。
